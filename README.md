
# RevenuePulse — Customer Revenue & Churn Intelligence Platform

## 📌 Overview

RevenuePulse is an end-to-end data analytics project designed to analyze customer behavior, revenue performance, customer segmentation, and potential revenue risk.

The project uses Python, SQL, and Power BI to transform raw business data into actionable business insights.

## 🎯 Objectives

* Analyze customer purchasing behavior
* Measure revenue and sales performance
* Segment customers using RFM analysis
* Identify customers showing signs of inactivity
* Estimate potential revenue at risk
* Build an interactive business intelligence dashboard

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQL
* PostgreSQL
* Power BI
* Scikit-learn
